## 1. Open Source Libraries & Frameworks

PyroNexa gratefully acknowledges the following open-source software packages:

### 1.1 Backend & Computational Stack
- **Python**: Core programming language (v3.11+ / v3.14). [Python Software Foundation](https://www.python.org/)
- **Flask**: Lightweight WSGI web framework and REST API routing. [Pallets Projects](https://palletsprojects.com/p/flask/)
- **Pandas**: High-performance data manipulation and multi-index aggregation. [NumFOCUS](https://pandas.pydata.org/)
- **NumPy**: Fundamental array computations and matrix operations. [NumPy Developers](https://numpy.org/)
- **SciPy**: Statistical functions and percentile calculations. [SciPy Community](https://scipy.org/)
- **Requests**: HTTP library for NASA FIRMS API communication. [Kenneth Reitz & Requests Community](https://requests.readthedocs.io/)
- **python-dotenv**: Environment variable management. [Saurabh Kumar](https://github.com/theskumar/python-dotenv)
- **Pytest**: Automated testing framework. [Holger Krekel and Pytest Developers](https://pytest.org/)
- **Gunicorn**: Production WSGI HTTP server for UNIX. [Benoit Chesneau](https://gunicorn.org/)

### 1.2 Frontend & Visualization Stack
- **Leaflet.js**: Mobile-friendly interactive JavaScript mapping engine. [Volodymyr Agafonkin](https://leafletjs.com/)
- **OpenStreetMap**: Standard global map tiles. [&copy; OpenStreetMap contributors](https://www.openstreetmap.org/)
- **CartoDB Dark Matter**: High-contrast dark basemap tiles. [&copy; CARTO &copy; OpenStreetMap contributors](https://carto.com/basemaps)
- **Esri World Imagery**: Satellite background imagery. [&copy; Esri](https://www.esri.com/)
- **Plotly.js**: Declarative scientific charting library. [Plotly Technologies Inc.](https://plotly.com/javascript/)
- **Bootstrap 5**: Responsive CSS grid and interface components. [Bootstrap Authors & Twitter, Inc.](https://getbootstrap.com/)
